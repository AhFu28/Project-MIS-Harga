FIRST RUN / SETUP

Siapkan workspace.

Aplikasi sudah dapat dideploy sebelum key AI tersedia. Dua secret berikut diperlukan untuk login dan menyimpan key provider.

1. Buat nilai secret di perangkatmu

Generator ini berjalan di browser. Password tidak dikirim ke server. Isi password yang ingin kamu pakai, lalu salin hasil ke Cloudflare. Jangan membagikan hasilnya.

Simpan master key dengan aman. Jangan menggantinya tanpa rencana; key provider lama tidak dapat didekripsi jika master key hilang. Mengganti password: ubah verifier lalu gunakan Keluar semua sesi.

2. Pasang pada Cloudflare

Workers & Pages → project-mis-harga → Settings → Variables and Secrets. Tambahkan kedua nilai di atas sebagai Secret runtime, bukan build variable. Simpan/deploy perubahan, lalu kembali ke halaman login.

Database D1 dibuat otomatis saat deploy melalui Wrangler. Tabel dibuat aplikasi saat request API pertama. Jika D1 provisioning gagal, lihat docs/DEPLOY.md di repository.

3. AI dan arsip bersifat opsional

Setelah login, masukkan Gemini/OpenRouter key pada Settings AI. Untuk Gemini, hanya gunakan proyek tanpa billing dan set build variable GEMINI_FREE_CONFIRMED=true, lalu rebuild. R2 belum diaktifkan secara default agar tidak mengaktifkan layanan berbasis pemakaian tanpa keputusanmu.

Data asli yang rahasia tidak boleh dikirim ke layanan AI gratis tanpa ketentuan yang sesuai. Review AI tetap saran; kamu yang menyetujui.
